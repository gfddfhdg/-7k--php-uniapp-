# 餐饮点餐系统 PHP+Uniapp 全开源

中小餐饮门店数字化需求持续增长，这套 PHP 后端搭配 Uniapp 前端的全开源餐饮点餐系统，集成堂食扫码点餐、外卖配送、到店自提、后厨打印、会员营销等全套能力，适合餐饮商家商用落地，也可供开发者研读学习。

系统由 PHP 服务端后台、Uniapp 用户端组成，依托 Uniapp 跨端特性，一份代码可编译微信小程序、H5 页面，无需重复开发。顾客到店扫描桌台二维码，即可直接点餐，选择菜品规格、提交订单，订单实时推送后厨并自动打印小票，减轻服务员压力，减少错单漏单，提升翻台率。外卖场景支持定位选店、地址填写、在线支付、配送状态追踪，同时支持到店自提，商家可在后台自由开关各类业务模块。

PHP 管理后台功能完善，商家可以完成菜品上下架、套餐设置、桌台管理，配置优惠券、满减、会员储值等营销玩法，后台自动生成营收、销量统计报表，直观查看门店经营数据。代码完全开源，结构清晰规范，开发者可以阅读整套 O2O 业务逻辑，自由进行二次开发，可按需拓展多门店、生鲜称重、骑手管理等模块，适配奶茶、快餐、中餐等多种业态。
